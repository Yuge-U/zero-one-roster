# ZERO ONE ROSTER

## v0.1.31

- JBA取込では、空欄・欠けている項目で既存値を消しません。値があるJBA項目は更新し、アプリ内のメモ・利き手・ロスター・在籍ステータス・写真・手動の所属先などは保持します。
- 「男性／女性」を「男／女」に、「2012年6月28日」やExcelの日付数値をYYYY-MM-DDへ変換します。不正な日付・性別は既存値を保持し、DATAに氏名と理由を表示します。
- JBA IDの文字幅・末尾の .0 と氏名の空白を正規化して照合します。ID未登録の同一選手は氏名（複数候補は生年月日も）で照合し、既存IDを維持して更新します。異なるJBA IDや重複候補は保留します。
- Excel読込ライブラリの読込漏れも修正しました。Excel・JBA JSONとも同じ取込処理を使用します。

## v0.1.30

- 学年フィルター・選手カード・詳細の学年を同じ判定に統一しました。ISO日時の生年月日も日付部分で扱い、生年月日がない場合は「中学2年」「中学校２年生」等を「中2」に統一して判定します。判定できない選手は「学年未設定」で絞り込めます。
- 詳細画面でISO形式の生年月日が空欄になり、他の項目の保存で消える問題も修正しました。

## v0.1.29

- ホームにステータスフィルター（在籍中・休止／退団・すべて）を追加しました。初期表示と「条件をクリア」は在籍中のみです。休止・退団の選手や過去の記録は削除しません。ステータス未設定の旧データは在籍中として表示します。

## v0.1.28

- 選手詳細の「所属チーム」で所属先を変更・解除できます。「在籍校」は別項目として維持します。手動で選んだ所属はJBA再取込時にも保持します。
- TEAMの「所属チームの管理」でチームを追加・編集できます。名称変更ではIDを維持し、選手・練習記録との紐づけを保持します。過去の練習内容は変更せず、画面には現在のチーム名を表示します。
- ホームの選手カードから「出席」とロスター（未設定・A〜E）を直接変更できます。出欠は表示中の日付とチームに記録し、すべてのチーム表示では選手の所属チームを使用します。所属未設定の選手はチーム未設定の出欠として記録します。ロスターは選手の現在の設定です。
- 変更は端末へ保存し、接続中はOneDriveへ自動同期します。

## v0.1.27

ROSTERからZERO ONE PRACTICEの練習プランを読み込み、実施した練習を日付・チーム別に記録できます。

1. PRACTICEで練習プランを保存し、ROSTERと同じMicrosoftアカウントでOneDriveに同期します。
2. ROSTERの「この日の練習」→「練習を記録」を開き、OneDriveからプランを読み込みます。端末保存のみの場合はPRACTICEの全体バックアップ（.data）も読み込めます。
3. 実施日・チーム・練習プランを選び、実施した項目、実際の時間、当日のメモを保存します。未登録のチームはこの画面で名前を指定して追加できます。
4. ROSTERのその日の一覧、またはRECORDSの「練習の実施履歴」で確認・編集できます。記録はROSTERのOneDrive同期対象です。

元プランへの書き込みは行いません。当日のプラン内容と参照版を記録に保存し、後のプラン変更は過去の記録に反映しません。競合中・前の版が不足しているプランは、PRACTICEで解決・同期してから読み込んでください。削除した記録も同期で復活しないよう削除情報を保持します。同日の別チームの活動・出欠を個別に同期します。

実Microsoftアカウントの受入確認は、公開後に両アプリを同じアカウントで接続して行ってください。自動テストは合成データと通信の代替処理を使います。

## OneDriveの接続操作

上部の共通バーに「未接続」「確認中」「接続中」「接続済み」「再接続が必要」を表示します。「OneDriveに接続」から直接Microsoftへ接続でき、アカウント選択を毎回強制しません。「接続設定」からアカウント変更とサインアウトを選べます。通信・アクセス許可の問題は未接続と区別します。旧画面の接続・アカウント変更・サインアウトのボタンは削除し、共通の操作だけを表示します。

「接続済み」は認証・接続の状態です。保存・同期の完了は各アプリの保存表示で確認してください。Safariの「履歴とWebサイトデータを消去」後は再接続が必要です。既存の保存領域・OneDriveのファイル形式・AppFolder権限を維持しています。

安全な更新通知・手動適用と検証／公開／ロールバック手順は [SAFE_APP_UPDATE.md](SAFE_APP_UPDATE.md) を参照してください。
